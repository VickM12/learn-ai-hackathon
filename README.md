# Vineyard Journal

A local Godot journal for a six-vine vineyard. Weather is filled from the zip code. Readings and notes stay on this machine.

## Try it

1. Install [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/).
2. Open this folder in Godot.
3. Press F5.

The Windows export preset names the company TwoBit Territories LLC. Code signing is off until a certificate exists. Export from Project, Export, Windows Desktop when you want the executable for a recording.
